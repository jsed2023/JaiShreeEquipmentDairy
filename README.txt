# JaiShreeEquipmentDairy-main

## Jai Shree Equipment Dairy Website

A modern, SEO-friendly dairy equipment website built with **Astro, TypeScript, Tailwind CSS v4, and shadcn/ui**.

Website: https://jaishreeequipmentdairy.co.in

## Requirements

Project run karne se pehle ye install karein:

- Node.js (LTS version recommended)
- npm
- Git (optional)

## Getting Started on Windows

### 1. Open Project Folder

Windows PowerShell ya VS Code terminal open karein.

```powershell
F:
cd F:\JaiShreeEquipmentDairy-main
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm run dev
```

Browser mein open karein:

http://localhost:4321

### 4. Create Production Build

```bash
npm run build
```

Production files `dist/` folder mein generate hongi.

### 5. Preview Production Build

```bash
npm run preview
```

Browser mein open karein:

http://localhost:4321

## Available Commands

| Command | Description |
| --- | --- |
| `npm install` | Install project dependencies |
| `npm run dev` | Start development server |
| `npm run build` | Create production build |
| `npm run preview` | Preview production build |
| `npm run astro` | Run Astro CLI |

## Deployment

The project can be deployed to Vercel.

Before deployment, run:

```bash
npm run build
```

Ensure the production build completes successfully.

## Troubleshooting

If dependencies are not installed correctly, try:

```bash
npm install
```

If the development server does not start, check your Node.js and npm versions:

```bash
node -v
npm -v
```

If the build fails, check the terminal error message and resolve missing dependencies or TypeScript errors.

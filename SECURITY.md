
# Security Policy

## Supported Versions

Jai Shree Equipment Dairy website is actively maintained. Security updates are provided for the latest production version.

| Version | Supported |
| ------- | --------- |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x: |
| < 1.0   | :x: |

## Reporting a Vulnerability

We take the security of our website and services seriously.

If you discover a security vulnerability, please report it responsibly.

**How to report:**

- Email: choudharydairy@outlook.com
- Subject: `Security Vulnerability Report – Jai Shree Equipment Dairy`

Please include the following details:

1. A clear description of the vulnerability.
2. Steps to reproduce the issue.
3. The affected URL, page, or component.
4. Screenshots or proof of concept, if available.
5. Any suggested mitigation, if known.

### What to Expect

- We will acknowledge your report within 3 business days.
- We will investigate and assess the reported issue.
- We will provide updates as the investigation progresses.
- If the vulnerability is accepted, we will work on a fix and deploy it as soon as reasonably possible.
- If the report is declined, we will explain the reason where possible.

### Responsible Disclosure

Please do not:

- Publicly disclose the vulnerability before we have had a reasonable opportunity to investigate it.
- Access, modify, or delete other people's data.
- Disrupt our website, services, or business operations.
- Exploit the vulnerability beyond what is necessary to demonstrate the issue.

We appreciate responsible security researchers who help us keep our website and users safe.

Thank you for helping improve the security of Jai Shree Equipment Dairy.
